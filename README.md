# Вскрытие замков в Москве — ПрофиМастер

Одностраничный сайт службы аварийного вскрытия замков. Статический HTML/CSS/JS, без сборки.

- `index.html` — разметка
- `style.css` — стили (шрифты Russo One + Play, акцент #15BCDF)
- `script.js` — автоплей видео, мобильное меню
- `media/` — видео и изображения (сгенерированы Higgsfield: Nano Banana Pro + Kling 3.0)

Публикуется через GitHub Pages из ветки `main`.
